# Netflix Clone 🎬

A front-end web application that replicates the core UI and movie-browsing experience of Netflix. Built to practice responsive design, API integration, and modern web development.

## Features
* 📺 **Dynamic Movie Fetching:** Pulls real-time movie data, trending shows, and top-rated categories using the TMDB API.
* 📱 **Fully Responsive:** Looks and works perfectly on desktop, tablet, and mobile displays.
* 🎬 **Trailer Previews:** Click on movie posters to instantly watch the YouTube trailer.
* 🔐 **Authentication UI:** Replicates the standard Netflix login and sign-up screens.

## Tech Stack
* HTML5 / CSS3
* JavaScript (ES6)
* The Movie Database (TMDB) API
